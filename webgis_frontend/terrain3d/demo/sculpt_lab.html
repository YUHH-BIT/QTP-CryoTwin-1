边界与事实核对

  • 项目：img2threejs 2.0.1（Apache-2.0，2026-11-05 发版），主仓约 20.4k stars。定位是 Agent Skill，不是开箱即用的网页服务。
  • 运行条件：Node ≥ 18、Git、Python ≥ 3.10，以及 Claude Code / Codex / OpenCode / Hermes 之一；核心 forge/ 脚本纯标准库、不需要 pip，README 未要求单独的 LLM API Key。
  • 宣称契约 ≠ 实际生成代码：README 与 docs/ARCHITECTURE.md 写的是 createObjectNameModel(spec, options) + ObjectSculptSpec + root.userData.sculptRuntime；但画廊里真实落地的 tropical-island/createTropicalIslandModel.ts 是无参工厂，没有 sculptRuntime，参数以 PALETTE / PROP_SLOTS 常量暴露，运行时句柄挂在 root.userData.tick / dispose 上。本页两种暴露方式都保留。
  • 单图看不到背面：按区域标 confidence，允许输出「只能做到示意」，不把视觉相似度当成测量真值。
  • 本页不调用任何外部服务、不联网、不加载网格或贴图，Three.js r160 已在本地；与吉隆沙盘的真实 DEM / 影像 / OSM 数据完全隔离。
