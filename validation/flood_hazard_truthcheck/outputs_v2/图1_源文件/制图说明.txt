图 1 源数据说明
================

1. 危险性等级_p99_1980-2023.tif
   - 数据类型：uint8；0 = 未淹没，1—5 = 危险性等级
   - 坐标系：EPSG:4326；网格 1560×3479；分辨率约 1 km
   - 生成口径：1980—2023 年逐日径流，逐像元 p99 阈值，时段最大值合成

2. 历史洪水点_2024_2025.shp
   - 323 个点；字段：year（年份）、level_p99（1 km 窗口最大等级）、
     dist_km（距河流距离，km）、basin（流域）
   - 坐标系：EPSG:4326；属性表编码 UTF-8

3. 随机对照点.shp
   - 323 个点；字段：level_p99、dist_km
   - 与历史洪水点按距河流距离分层匹配

4. 青藏高原边界.geojson
   - 制图范围边界

建议制图：
- 危险性栅格：0 值透明；1—5 级用 YlOrRd 或 Reds 渐深配色
- 历史洪水点：蓝色圆点，大小 4—6 pt
- 随机对照点：浅绿色小点，透明度 40%—60%
- 图层顺序：栅格 → 随机对照点 → 历史洪水点 → 边界

5. ArcGIS 色带文件（与论文图 1 配色完全一致）
   - 危险性等级_YlOrRd.clr
     ArcGIS 色表；1—5 级 rgb。0 级依赖栅格 NoData（本 tif 已设 NoData=0）显示透明。
     ArcGIS Pro：栅格图层 → 符号系统 → 彩色地图（Colormap）→ 导入色表（Import Colormap），选此文件。
     ArcMap：栅格 → 属性 → 符号系统 → 彩色地图 → 添加色表（Add Colormap）。
   - 危险性等级_YlOrRd_含NODATA透明.clr
     在上述基础上显式写入 0 级 alpha=0（Pro 的 RGBA 色表可用；若导入报错改用上一个）。
   - 危险性等级_p99_1980-2023_色表.tif
     已内嵌色表并保持 NoData=0 的栅格，ArcGIS 打开即呈图 1 配色，可直接叠加点位出图。
   - 5 级色值（YlOrRd，vmin=1、vmax=5），十六进制与 RGB：
     0 = 未淹没：按 NoData 处理（本 tif NoData=0）或设为全透明（alpha=0）
     1 = #ffffcc = 255,255,204
     2 = #fed976 = 254,217,118
     3 = #fd8c3c = 253,140,60
     4 = #e2191c = 226,25,28
     5 = #800026 = 128,0,38
   - 点位与边界色（沿用图 1）：
     历史洪水点 = #1f77b4 = 31,119,180（实心圆点，4—6 pt）
     随机对照点 = #2ca02c = 44,160,44（小点，透明度 40%—60%）
     青藏高原边界 = #000000 = 0,0,0（黑色线，0.6 磅）
   - 重新生成：python ..\..\code\export_arcgis_colorramp.py
