# 洪水危险性方法验证方案（v2）

- 日期：2026-11-23
- 状态：**方法设计已完成；脚本未编写；验证结果未产出**（见第 8 节未完成项）
- 适用对象：`flood_workflow` 的**青藏高原全域**危险性等级栅格 H（0–5 级），不验证风险 R
- **验证空间范围：整个青藏高原**——TP_China 边界内、全域栅格覆盖的 73.437–104.690°E / 25.809–39.822°N（约 1 km 网格，1560×3479）。
- 确认口径：**真值只用 SHP 事件集**；覆盖度复核 + 区分能力检验两者都做；时间留出 1980–2023 生成 → 2024–2025 验证

---

## 1. 验证命题与边界

本方案只回答一个问题：**在整个青藏高原尺度上，模型划定的高危险等级区，是否系统性地对应历史洪水发生地？**

分两节给出结论：

| 节 | 命题 | 核心指标 | 能说什么 / 不能说什么 |
|---|---|---|---|
| A | 覆盖度复核 | 命中率 + 随机基线 + 提升倍数 | 能说"点位落进淹没区的比例是否高于面积基线"；不能说方法有多大预报技巧 |
| B | 区分能力检验 | ROC-AUC + 等级单调性 | 能说"等级高低能否区分洪水点与非洪水点"；不能说某点某年是否会被淹 |

**明确不做**：风险 R = H × E × V 的定量验证（含暴露度与脆弱性，洪水点位无法约束）；任何预测数字；防洪决策用途。

## 2. 被验证方法回顾

`flood_workflow/step3_hazard.py` 的流程（与 `threshold_batch_hazard.py` 算法一致）：

1. 逐日判定：`runoff >= grid_threshold_{p}p.tif` → 淹没，保留 runoff 值，否则置 0；
2. 时段最大：时段内逐像元取最大值，得到淹没强度场；
3. 归一化：淹没区内 min-max 到 [0,1]；
4. 分级：淹没区内 20/40/60/80 分位数 → 1–5 级，未淹没 = 0。**各级面积各占淹没区约 20%，是相对分级**；
5. 输出：uint8 tif，nodata=0，网格 1560×3479，分辨率 0.008983°（约 1 km），范围 73.437–104.690°E / 25.809–39.822°N。

> 关键推论：因为分级是淹没区内的相对分位，"≥3 级命中率"不是绝对强度指标，不同阈值、不同时段的结果不可直接比较。横向比较必须同时报淹没面积占比。

## 3. 真值数据与清洗（实测）

### 3.1 SHP 事件集

真值只用一个来源：人工编目的历史洪水灾害事件点。

| 文件 | 记录数（实测） | 可用字段 |
|---|---:|---|
| `2004_2025.shp` | 1,231 行 | 地名(F5)、Began/Ended、Dead、Displaced、losses、MainCause、来源 URL |
| `1980_2003.shp` | 20 行 | 同上；Began 格式混杂 D/M/Y 与 Y/M/D，Start_Year 字段全为 0 |

选择理由：每条记录对应一次有据可查的灾害事件，有灾情描述、成因和来源链接，可溯源，无需额外去重。

### 3.2 已知限制（实测）

1. **样本量小**：两期合计 1,251 点，其中留出验证期（2024–2025）只有 328 点（2024: 180，2025: 148）。AUC 置信区间会明显偏宽（粗估 ±0.05 量级，**推算值，待 bootstrap 实测**），报告中必须标注这一限制。
2. **时间分配不均**：2004–2025 的 1,231 点中，2024–2025 占 328 点，2010 年及以前不足 200 点；逐年指标不可比，不做早期逐年比较。
3. **日期缺失**：2004–2025 有 10 条、1980–2003 有 1 条无法解析年份，归入 year=0 单独统计，不参与留出验证。
4. **来源偏差**：事件集偏重有灾情记录、被人工编目的洪水，对无灾情记录的小规模洪水存在漏记；结论只代表"被记录事件"的空间格局。

### 3.3 清洗规则（待脚本实现）

- 用几何坐标读取（属性表 lat/lon 字段为 0，不可用）；
- 年份从 `Began` 解析，兼容 D/M/Y 与 Y/M/D 两种写法；无法解析的归入 year=0 并单独统计；
- 坐标统一到 EPSG:4326；
- TP 边界（TP_China.geojson）+ 栅格覆盖范围（73.437–104.690°E / 25.809–39.822°N）双重裁剪，与既有口径一致。

## 4. 现有验证的诊断（实测）

现有 `hazard_verify_full.py` / `step4_validation.py` 报"命中率 = 点位落入等级>0 比例"；旧口径下纯 SHP 部分为 1,248 点、76.9%（全时段、1 km 容差、p99）。该数字**不能单独作为验证结论**，原因：

1. **无对照基线**：p99 全时段栅格淹没面积占研究区 11.534%（实测 625,978 / 5,427,240 像元）；1 km 容差窗口进一步放大命中。命中率必须除以基线才说明问题。
2. **时间泄漏**：用的栅格是 1980–2025 全部径流取时段最大，验证点位也来自同期 → 待验证事件本身参与了栅格生成，属循环论证。
3. **时间采样偏差**：见 3.2 第 2 点，近年点位密度远高于早期，总体命中率被近年样本主导。
4. **阈值语义可疑（前置阻塞项）**：`threshold_audit_2024_2010.md` 实测，现有 `grid_threshold_*.tif` 与同年径流均值的逐像元相关系数为 −0.93 ~ −0.99（若为真正的历史分位数应 >0.8 正相关），99p 超阈比例 3.2–3.7 倍于理论 1%。**说明阈值与径流不同源或量纲/方向不一致**，此时 step3 的"淹没判定"边界不可信。

> 第 4 项必须在验证前解决：用 `step2_threshold.py --start 1980-01-01 --end 2023-12-31` 重新生成五个阈值栅格，并重新做阈值语义体检（超阈比例 + 空间相关）。否则第 5 节 A/B 两节指标失去物理意义。此步骤**尚未执行**。

## 5. 验证设计

### 5.1 时间留出（避免泄漏）

| 项 | 设定 |
|---|---|
| 阈值计算时段 | 1980-01-01 ~ 2023-12-31（严格早于验证期） |
| 危险性生成时段 | 1980-01-01 ~ 2023-12-31，输出 `1980-01-01_to_2023-12-31_basin-all_hazard.tif` |
| 验证点位时段 | 2024-01-01 ~ 2025-12-31 |
| 可用 SHP 点数（实测） | 328 点（2024: 180，2025: 148） |
| 对照口径 | 逐年 leave-one-out（每年用其余年份生成栅格验证该年）——本次不做，仅列为后续选项 |

> 328 点是本次验证的全部真值样本，AUC 与命中率的置信区间需由 bootstrap 实测给出，不得省略。

### 5.2 抽样与对照

- 正样本：清洗后的 2024–2025 年 SHP 事件点（328 点，扣除无法解析日期后以实际数为准），覆盖整个青藏高原 TP 边界内的栅格范围。
- 负样本：在**全青藏高原栅格有效区**内随机撒等量点，按距河流距离分层（若河网数据缺失，改用高程/坡度分层，并在报告中声明替代）。负样本同样做 TP 边界 + 栅格范围裁剪。
- 位置容差：0 / 1 / 3 / 5 km 平行抽样，主口径 1 km；窗口内取**最大等级**（沿用现有工具 `common.sample_max_level`）。
- 不确定度：对点位做 1,000 次有放回 bootstrap，报指标 95% 置信区间。

### 5.3 指标定义

**A 节 · 覆盖度复核**

- 命中率 Hit = 落在等级>0 的点数 / 有效点数。
- 背景基线 Base = 淹没像元数 / 研究区有效像元数（同一栅格、同一边界）。
- 提升倍数 Lift = Hit / Base。Lift ≤ 1 表示不比随机落点强。
- 输出：SHP 的 Hit、Base、Lift、95% CI；附 0/1/3/5 km 容差曲线。

**B 节 · 区分能力检验**

- ROC-AUC：以等级 0–5 为评分（0 = 负），正样本为 SHP 洪水事件点、负样本为随机点。AUC = 0.5 为随机，>0.7 才认为有区分能力。
- 等级单调性：统计正样本落在 0/1/2/3/4/5 各级的比例 Pk，与负样本比例 Nk 比较，要求 Pk/Nk 随 k 单调不减；用 Spearman 相关检验趋势。
- 阈值敏感性：对 p10/50/90/95/99 五张（重算后）栅格分别算 AUC 与 Lift，观察结论是否只在某一阈值成立。
- 全域与分区：先报**整个青藏高原**的总体 Hit 与 AUC，再按流域/省份分组报，用分区结果识别全域总体指标掩盖的系统性漏判区；分区统计不改变全域验证范围。

### 5.4 判读边界

- 命中率是**覆盖度**不是精度；AUC 是**排序能力**不是校准。两者都不能推出"某年某地会淹多深"。
- 相对分位分级意味着"5 级"只表示在当次淹没区里强度排前 20%，不同时段/阈值的 5 级不可比。
- 真值来源偏差：事件集偏重有灾情记录、被人工编目的洪水，对无记录事件存在漏记；结论只代表"被记录事件"的空间格局。
- 样本量限制：留出期 328 点，分区统计后每组样本更少，分区结果只作定性参考，不作独立结论。
- 结论限定为演示级空间格局合理性，**不可用于防洪决策**。
